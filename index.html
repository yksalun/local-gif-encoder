How the Encoder Works in Plain JavaScript

  1. Canvas normalization: Each source image is scaled cleanly onto an offscreen HTML5 Canvas so every frame shares exact width and height dimensions.
  2. 256-color quantization: Pixels are mapped to a balanced 216-color RGB cube plus a 40-step grayscale ramp, with optional Floyd-Steinberg error diffusion for smoother gradients.
  3. Variable-width LZW compression: Encodes 8-bit palette indices into standard GIF89a sub-blocks with dynamic dictionary reset at 4,096 codes.
  4. Zero network transfer: Output bytes become a local Blob URL in RAM — ideal for privacy-sensitive workflows and offline PWAs.
import { encodeGif } from './src/gif-encoder.js';

const gifBytes = encodeGif(
  [
    { rgba: frame1ImageData.data, delayMs: 400 },
    { rgba: frame2ImageData.data, delayMs: 400 },
  ],
  { width: 360, height: 240, loop: 0, dither: true }
);

const blobUrl = URL.createObjectURL(new Blob([gifBytes], { type: 'image/gif' }));
